# EngineRoom — Gym Management SaaS

Multi-tenant gym management platform built for Nigerian gym businesses. Gym admins manage members, trainers, billing, and plans. Members self-serve their profile, check-ins, BMI, and AI-generated workout plans.

**Live:** Deployed on Vercel · **Stack:** Next.js 15 · Supabase · Paystack · Claude AI · shadcn/ui

## What to Continue Next

Suggested order based on business impact:

1. **Paystack webhook route** — without it, online payments can't be confirmed automatically. Trainer/member access can't be auto-provisioned after payment.
2. **QR check-in** — member gets a QR on their dashboard; admin scans it to log attendance.
3. **Trainer dashboard** — assign members, view their workout/BMI progress.
4. **Member + Trainer detail/edit pages** — full CRUD for admin.
5. **PWA** — service worker, manifest, offline page. Critical for Nigerian mobile users.
6. **Notifications (send)** — admins push announcements, payment reminders, plan expiry alerts.

## Local Development

```bash
# from repo root
pnpm install
cd web && pnpm dev
```

Requires a `.env.local` in `web/`:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
PAYSTACK_SECRET_KEY=
NEXT_PUBLIC_PAYSTACK_PUBLIC_KEY=
ANTHROPIC_API_KEY=
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
